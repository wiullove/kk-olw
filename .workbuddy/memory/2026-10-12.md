## 把投资分析知识图谱页融合进 kk-owl（JBoltAI 本体语义平台演示页）

- 目标：让「导入知识文档 → 语义解析 → 生成并确认本体 → 展示本体关系图谱」在平台内形成闭环。
- 新增文件：
  - `force-graph.js`：可复用的本体力导向图引擎（多实例），API：`window.OntoGraph.create(container, data, opts)`，支持聚类/自由布局、关系标签、缩放平移、节点拖拽、hover 高亮、搜索、按本体显隐、渐进生长（`resetReveal`/`revealGroup`/`revealAll`）、`on('select'|'hover'|'stats')` 回调、`fit/resize/pause/resume`。
  - `ontology-data.js`：`window.INVEST_ONTOLOGY`，10 类本体 / 54 概念 / 68 关系 / 186 属性，`stats` 由数据实时计算，节点含 `desc` 与 `props`。
- 改动：
  - `index.html`：本体建模面板改为「销售业务本体 / 投资分析本体」双签页，投资分析签页为图谱工作区（图例栏 + 工具栏 + `#ogStage` 画布 + `#ogEmpty` 引导空态）；右侧检视卡拆为 `#salesInspector` 与 `#ogInspector`；导入弹窗 preview 阶段换成真实图谱预览（`#ogPreviewStage`、`#replayPreview`）；企业知识列表新增投资分析手册条目；新增脚本引用与 favicon 占位。
  - `app.js`：接线导入链路（解析进度 → 预览逐层生长 → 确认 → 跳转建模面板逐层生长展示图谱），图例/工具栏/搜索/详情面板绑定，写入工作空间联动（知识条目、总览指标与活动流、洞察引擎上下文改为投资分析口径）。
  - `styles.css`：新增 `og-*` / `cg-tab` / `ins-*` 等样式，配色与平台浅色工作台一致；移动端隐藏图例与关系标签。
  - `package.json`：build 脚本补充两个新 JS 文件。
- 约定/经验：
  - 该演示页所有静态资源使用根路径（`/app.js`），本地预览需用 `node server.js`（可用 `PORT=3131`）而非 file:// 打开。
  - 新签页内容必须插在 `.model-canvas` 卡片内部；`.model-layout` 是 `minmax(0,1fr) 260px` 两列网格，插成第三个子元素会把图谱挤进 260px 窄列。
  - 冒烟验证方式：Node 22 自带全局 `WebSocket`，用 Chrome `--headless=new --remote-debugging-port` + CDP 直接驱动页面（无需安装 puppeteer），脚本见 `/tmp/kk-owl-smoke.mjs`、`/tmp/kk-owl-smoke2.mjs`（临时文件）。

## 本体实例数据层（ABox）随文档导入

- 设计原则：导入链路分两层展示 —— 模式层 TBox（概念/属性/关系定义）与实例层 ABox（具体实例 + 属性断言 + 实例间关系）。实例随文档一并解析，按 `rdf:type` 挂载到对应本体概念，与骨架同批写入本体库。
- 新增 `ontology-instances.js`：`window.INVEST_INSTANCES`，34 实例 / 37 实例关系 / 25 字面量属性 / 62 断言 / 130 三元组。数据契约：
  - `instances[]`：`{ id, uri('inv:XXX'), cls, g(本体分组), concept(对应本体概念 id), label, desc, props:[[中文名, 值, rdf谓词]] }`
  - `links[]`：`[源实例id, 目标实例id, 关系标签]`
  - `graph`：`{ groups, nodes, links }`，可直接喂给 `OntoGraph.create` 渲染实例图谱
  - 查询 API：`get(id) / out(id) / inOf(id) / ofConcept(conceptId) / byConcept / triplesOf(id)`
  - 关键：`concept` 字段必须命中 ontology-data.js 里的节点 id（如 `InterestRateRisk` → `RateRisk`）；`uri` 在派生阶段统一补写，不要只建在 graphNodes 上。
- 展示四阶段：解析中给六项抽取流水线（含实例/RDF 三元组，青色区分）→ 预览给第 4 张卡 + 「本体骨架 / 实例图谱」双视图（按本体逐批挂载、实例 chips、三元组明细）→ 成功页四格统计 → 画布给概念实例角标 + 图例徽标 + 「实例层」开关 + 检视面板「实例样本」下钻。
- `force-graph.js` 新增 `opts.badge(node) => number` 与 `setBadges(on) / badgesVisible()`，在节点右上角画实例计数角标。
- 踩坑：`styles.css` 是长单行压缩风格，同一选择器的**后定义者胜**。`.extraction-grid{repeat(3,1fr)}` 位于文件后段（约 48.7k 偏移），新增的 `repeat(4,1fr)` 必须追加到文件最末尾才生效，不能只插在 `og-*` 区块后面。
